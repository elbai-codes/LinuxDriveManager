## Introduction
This LinuxDriveManager release is an improved version of the original text-only LinuxDriveManager!  
It utilizes the Zenity GUI tool in order to give the script a friendly point-and-click interface, letting noobs actually manage drives without spending most of their time in a dreaded terminal!
## Usage
First, go into your home directory, using ``cd``.  
``cd ~/``  
Then, use ``git`` to clone the directory.
``git clone https://github.com/elbai-codes/LinuxDriveManager/``  
Now, go into the directory that ``git`` just made.  
``cd ./LinuxDriveManager``  
Give the script permissions to run using ``chmod``!
``chmod +x ./driveman-zenity.sh``  
And finally, run the damn script! (Make sure to use ``sudo bash``, or else the script won't work!)  
``sudo bash ./driveman-zenity.sh``
